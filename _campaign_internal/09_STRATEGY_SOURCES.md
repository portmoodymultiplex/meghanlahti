## Estimates (clearly labeled as such in the doc)

### Polling-station turnout assumptions per neighbourhood
The strategy doc's chart note already says: *"Derived from demographic data, historical turnout trends, and strategic assumptions. Not based on official voter file data."*
- These are working assumptions, not verified projections. Built from 2022 polling-station results + general municipal turnout patterns + neighbourhood character.
- Should be tightened with voter file data once the campaign acquires it.

### Per-neighbourhood demographic descriptions
- "Multi-family condos, younger professionals" / "Stable 1950s single-family" / "~91% owner-occupied" type descriptions
- Built from: Census 2021 dissemination-area-level data (statcan.gc.ca) + BC Stats neighbourhood profiles + walk-the-neighbourhoods knowledge
- Anything in the strategy doc beyond Census-level granularity is informed estimate, not hard data

### "5,400+ vote target"
- Built from: 2022 floor (4,938) + estimated activation among under-voting renters and young families
- Methodology: rough, conservative. Treats 2022 as a floor, assumes some incremental activation, accounts for SSMUH-energized opposition turnout
- Not a model, a working target

### Vote-share / housing-sentiment categorizations
- "Activate / Retain / Convert / Contain" labels per neighbourhood are strategic judgment calls, not survey-derived

## What I'd push back on first if I were a senior advisor

In case it's useful to know what I'm self-aware about:

1. The per-neighbourhood turnout estimates need real voter-file data to be more than directional.
2. The "5,400+ vote target" is a directional aim, not a model. I'd want to firm up the activation assumptions.
3. The opponent profile (Haven Lurbiecki) is sourced to public records but the "voted no on virtually everything" claim should be checked vote-by-vote before any of it goes into mailers or attack content.
4. The contrast strategy ("Haven promises / Meghan delivers") works only if Meghan's "delivered" record stands up to public scrutiny — which is exactly what the website audit is designed to validate before launch.
